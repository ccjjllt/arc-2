

Looking at the demos, I can identify the pattern:

1. Find the interior of the grid (excluding the 1-cell border)
2. Identify "special" cells (non-7 values) in the interior
3. Find the bounding box of special cells
4. Create a block by adding a 1-cell border (border color, with 7 corners) around that bounding box
5. Place this block twice in a 15×15 grid at positions (2,2) and (8,8)

**Test input interior** (rows 1-4, cols 1-3):
```
7 7 7
8 8 8
8 4 7
8 7 4
```

Special cells (non-7) have bounding box rows 1-3, cols 0-2:
```

8 7 4
```
