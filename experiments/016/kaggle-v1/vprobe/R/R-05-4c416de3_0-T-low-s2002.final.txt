To solve the ARC puzzle, we need to understand the transformation rule from the input to the output grids in the demos.

**Rule Analysis:**
1.  **Identify Rectangles**: The grid contains one or more rectangular regions defined by a border of `0`s. The background is a specific digit (e.g., 1 in Demo 1, 8 in Demo 2, 2 in Demo 3, 3 in the test).
2.  **Identify Interior Numbers**: Inside each `0`-bordered rectangle, there are one or more non-zero, non-background digits.
3.  **Projection**: Each interior number "projects" outwards towards the nearest corner of the rectangle based on its position relative to the center or simply towards the corner it is closest to. Specifically:
    *   If a number is in the top-left quadrant of the interior, it projects to the top-left corner.
    *   If top-right, to top-right corner.
    *   If bottom-left, to bottom-left corner.
    *   If bottom-right, to bottom-right corner.
4.  **Pattern of Projection**:
