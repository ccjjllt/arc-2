To solve the ARC puzzle, we need to determine the pattern that transforms the input seed into the full output grid.

**Step 1: Analyze the Demos**

*   **Demo 1:**
    *   Input: 7x7 grid. The top-left 3x3 subgrid contains non-7 values:
        ```
        3 7 4
        7 3 4
        4 4 4
        ```
    *   Output: 7x7 grid. The pattern repeats with a period of 4 in both dimensions. The 4x4 tile is:
        ```
        3 7 4 7
        7 3 7 4
        4 7 3 7
        7 4 7 3
        ```
    *   Observation: The tile size is $4 \times 4$, which is $(3+1) \times (3+1)$ where 3 is the seed dimension.
    *   Mapping: The non-7 values in the seed (3 and 4) appear on specific diagonals in the tile.
        *   Value 3 is at $(0,0), (1,1)$ in the seed ($r-c=0$). In the tile, 3 is at $(0,0), (1,1), (2,2), (3,3)$ where $(r-c) \equiv 0 \pmod 4$.
        *   Value 4 is at $(0,2), (1,2), (2,0), (2,1), (2,2)$ in the seed. Let's look at the most frequent $r-c \pmod 4$ for 4 in the seed:
            *   $(0,2) \to -2 \equiv 2$
            *   $(1,2) \to -1 \equiv 3$
            *   $(2,0) \to 2$
            *   $(2,1) \to 1$
            *   $(2,2) \to 0$
            *   Frequencies: 2 appears twice, others once. The dominant diagonal for 4 is 2.
            *   In the tile, 4 is at $(0,2), (1,3), (2,0), (3,1)$ where $(r-c) \equiv 2 \pmod 4$.
    *   Rule Hypothesis: Identify unique non-7 values. For each value, determine the "primary" diagonal index $k = (r-c) \pmod N$ (where $N = \text{seed\_dim} + 1$) based on the most frequent occurrence in the seed. Then, fill the $N \times N$ tile such that $T[r][c] = v$ if $(r-c) \equiv k_v \pmod N$, else 7. Finally, tile this $N \times N$ block to fill the grid.

*   **Demo 3:**
    *   Input: 12x8 grid. Seed is 4x3 (top-left).
        ```
        9 7 0
        7 7 0
        7 9 0
        0 0 0
        ```
    *   Output: 12x8 grid.
    *   Horizontal period: The pattern repeats every 4 columns. So $W = 3+1 = 4$.
    *   Vertical period: Let's check the rows.
        Row 0: `9 7 0 7 ...`
        Row 4: `7 7 7 7 ...`
        Row 9: `9 7 0 7 ...`
        It seems the vertical period is not simply $H+1 = 5$. Let's look at the "tile" for the vertical direction.
        Actually, looking at Demo 3 output, the pattern is generated by a 2D periodic function.
        Let's re-evaluate the diagonal rule for Demo 3 with $W=4$.
        Values: 9, 0.
        For value 9:
        Positions in seed: $(0,0) \to r-c=0$, $(2,1) \to r-c=1$.
        Frequencies: 0 (1 time), 1 (1 time). Tie.
        For value 0:
        Positions in seed: $(0,2) \to 2$, $(1,2) \to 3$, $(2,2) \to 0$, $(3,0) \to 3$, $(3,1) \to 2$, $(3,2) \to 1$.
        Frequencies: 2 (2 times), 3 (2 times), 0 (1 time), 1 (1 time). Tie between 2 and 3.
        
        Let's look at the actual output tile (first 4 columns of first few rows) to deduce the mapping:
        Row 0: `9 7 0 7` -> 9 at $c=0 (r-c=0)$, 0 at $c=2 (r-c=2)$.
        Row 1: `7 7 7 7`
        Row 2: `7 9 7 0` -> 9 at $c=1 (r-c=1)$, 0 at $c=3 (r-c=-1 \equiv 3)$.
        Row 3: `0 7 0 7` -> 0 at $c=0 (r-c=3)$, 0 at $c=2 (r-c=1)$.
        
        This shows:
        9 appears at diagonals 0 and 1.
        0 appears at diagonals 1, 2, 3.
        Wait, $(3,2)$ has $r-c=1$, value 0. $(2,1)$ has $r-c=1$, value 9. Conflict?
        Let's check the output at $(2,1)$ and $(3,2)$.
        Output Row 2: `7 9 7 0 ...` -> $(2,1)=9$.
        Output Row 3: `0 7 0 7 ...` -> $(3,2)=0$.
        So diagonal 1 contains both 9 and 0? No, $(r-c) \pmod 4$ for $(2,1)$ is 1. For $(3,2)$ is 1.
        This contradicts the "one value per diagonal" hypothesis.

    Let's reconsider the structure.
    In Demo 1, the tile was $4 \times 4$.
    In Demo 3, the horizontal period is 4. What is the vertical period?
    Row 0: `9 7 0 7`
    Row 4: `7 7 7 7`
    Row 8: `7 0 7 9`
    Row 9: `9 7 0 7` (Same as Row 0)
    So the vertical period is 9.
    Why 9? Seed height is 4. $9 = 2 \times 4 + 1$? Or maybe related to the grid size?
