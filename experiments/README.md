## 文件阅读方式

- `execution/`记录当时的启动、配额、版本及状态，不能当作当前实时状态。
- `kaggle*`及带`vN`的目录通常是冻结的上传包或下载输出，重复源码可能属于不同版本证据。
- `scoring-*`、候选池、`run.json`、日志和逐query账本用于解释实际结果；空的`final.txt`也可能记录未产出答案。
- 大权重、optimizer和部分数据池不进Git，但保留在本地；具体身份见各轮manifest与progress。
