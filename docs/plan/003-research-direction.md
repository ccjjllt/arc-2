# 003 — 深度调研与方向选择

日期：2026-09-29。对应进展：`docs/progress/003-research-direction.md`。

## 背景与目标

用户澄清：30.14 分来自复制他人的公开 Notebook 后直接试提交，没有自主改动，因此不能以此限制研究路线。目标仍是 ARC Prize 2026 — ARC-AGI-2 金牌，进一步争取奖金。

本轮回答三个研究问题：哪些高分有可信且可比较的证据；哪些代码、模型和数据真正公开可用；在 L4×4 的条件下应先实现什么。

## 研究假设

- 高分联网模型的能力可以启发离线方案，但它的分数和权重不能直接转移到本赛。
- 相比继续调整复制 Notebook 的阈值，新增 ARC2 规则数据及定向训练可能更值得投入。
- 小型网格模型和程序生成模型具有不同长处，互补收益需要逐题结果证明。
- 参数很少不代表训练成本小；“开源仓库存在”不代表训练权重、完整代码和推理预算已可复现。

## 调研方案

1. 重试 Kaggle MCP，只读获取规则、数据说明、公开 Notebook 与讨论；部分接口无权限时继续使用可访问的公开来源，不把认证排查变成研究主体。
2. 查 ARC Prize 与 OpenAI 官方资料，核实 Astra 的 ARC2 成绩及评测方式。
3. 阅读高分公开 Notebook 的实际源码、原作者说明与模型卡，区分标题分数、模型关联最高分、具体版本提交分数。
4. 筛选 ARC-GEN、NVARC、带执行步骤数据、程序轨迹数据等资源，记录可下载对象与训练覆盖。
5. 比较专用网格微调、程序搜索、递归小模型、扩散和大模型压缩，给出主线及次线。
6. 对关键疑点进行小规模只读核对，例如论文题目 ID 与官方训练/评估目录的集合关系；不运行模型训练。

## 需要实现或修改的代码

本轮不实现求解器。只修改研究文档、README 与协作约定，纠正历史试提交的定位。临时检索代码仅用于读取公开资料，不进入项目训练框架，不新增测试文件。
