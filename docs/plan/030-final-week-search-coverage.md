## 5 单因素实验与最小实现交接

### 假设与固定项

假设：正确输出的一部分累计概率介于0.1与0.2；放宽剪枝能在相同计算预算下增加最终两槽正确query，而不因后续视角／query被挤占产生更大损失。

- A：原`max_score = -np.log(0.2)`；B：`-np.log(0.1)`，位置见[原源码690行](../../experiments/021/reference/failed-in-aimo-v1.source.py#L690)。这是整条输出路径累计概率，**不是单token置信度**。
- 固定原sft139 BF16 V1、TTT一epoch／128步、TTT增强seed1、推理增强seed2、原16视角及批布局、8视角重评分、原B4。
- 固定540秒DFS、1200秒task软检查、42600秒正式全局截止；不改缓存、prefill、草稿路径、模型结构或排序。
- 新配对显式固定同一个Python hash seed，并沿用到挑战正式版本；这相对023是可重复性差异，不能悄悄声称只用正式历史30.14作为单因素对照。决定依据为本轮同配置A/B；023仍是比赛保留项。

### 先做CPU准备，GPU会话只用于验证

1. 对冻结原V1、023成功包、拟用030包做**一次有时限的差异清单**：权重SHA、工具版本、镜像、hash/随机种子、输入模式、TTT、DFS、B4、截止。历史原镜像未知等写未确认，不再为复现33.89展开无限环境追踪。
2. 从已有025的40题准备一个固定开发／压力配对面板；阈值假设在看新输出前固定，不在026十六题调参救训练结果，也不在C23调排序或选seed。已知第二槽和第三批收益样本单列为压力证据，不通过白名单影响部署。
3. 另从当前Kaggle官方120题中按输入长度、单／多query冻结一个不与首轮重叠的扩展回归面板（建议约40题），完整保留每题query。C23若纳入，仅用于已暴露的固定方案回归评估；不据其结果改阈值、B4或seed，也不挑选变体。结果仅用于按预定条件继续或停止，不作独立确认。具体IDs、顺序、预算和文件SHA必须在GPU前写manifest；本文件未伪称它们已冻结。
4. 评分直接使用027已核验的本届Kagglechallenge／solutions快照，不再先用不匹配GitHub版本。预测、完整分母和策略先冻结，再手动运行已有评分器。

### 机制配对与完整同预算评价

- 少数压力题的机制配对使用同一次TTT adapter，分离每臂推理临时状态。各臂部署成本均记入该次完整TTT耗时，不能把第二臂TTT记0。这部分只回答阈值改变的局部行为，不替代完整预算评价。
- 原始重复A/A只在少数已知压力题做；若原版重复漂移与A/B收益同量级，结果标为不确定，不挑有利运行。A/B先后顺序按预先规则平衡，避免一律后运行者受到更多全局截止影响。
- 完整task按各臂实际TTT＋DFS＋新增候选重评分成本计时。机制包装若共享TTT，不能用共同真实起点把另一臂的时间算入本臂1200秒，也不能赠送额外预算。
- 除原task上限外，**必须有两臂相同的整体时间预算**，不能只比较全部题跑完后的准确率。40题可先用约正式240题六分之一的求解预算作为压力口径，准确值先扣实测一次性加载开销后冻结。按题数缩放仍是代理，不代表已重现隐藏题分布。
- 上述每臂约7100秒的参照以各臂使用4×L4为前提；完整评价顺序使用同一组4卡，不把2＋2卡的相同墙钟称为相同正式预算。首轮总4小时上限还要容纳加载、重复控制和收尾，不能直接塞入两次7100秒再临时延时；实施前冻结扣除这些开销后的相同有效预算，必要时在读新结果前缩小面板，并明确更紧压力口径。
- **整体预算评价默认采用两个独立、同种子、同面板、同环境和相同墙钟截止的完整运行**，原任务队列及截止检查不改。报告两次TTT的指纹与运行波动，不冒称完全相同adapter；同adapter小配对仅作机制证据。这样避免为了共享TTT再开发逻辑时钟和新调度框架。若重复噪声无法排除，结论为不确定，不据历史base替代本轮对照。
- 所有任务/query均保留在分母；结束预算导致的未搜索或占位不得删除。较低阈值在有截止时不保证候选集合包含A。

### 指标与停止条件

主指标为官方说明的query EM@2微平均，列新增、丢失、净增及涉及的独立task数。辅助报告首槽／仅第二槽、raw/scored oracle、每query完成的4批数量、未搜索、空候选、TTT/DFS/评分成本及峰值显存。

只有以下条件同时成立才晋级：

1. 同预算EM@2净增严格为正；增加oracle但两槽净0／负不通过。
2. 初轮收益不是仅一个任务的偶然改动：至少两个不同task贡献新增；这是赛前实用筛选条件，不是统计显著性证明。
3. 固定策略扩展回归仍净增为正，单列后query／晚批视角的覆盖损失与原第二槽正确样本；不能靠删失败分母通过。
4. 相同截止下的尾部覆盖有实测或透明的成本压力证据；无法在12小时内兑现的不限时收益不晋级。小面板的预算外推限制须保留。

任一轮净0／负，结束0.1配方；不扫0.15／0.07／0.05、不改B4救结果、不切换seed挑最好、不复活026／027／028。若只有小样本+1或预算结论不清，保存为不充分证据，优先保住可用正式方案。
